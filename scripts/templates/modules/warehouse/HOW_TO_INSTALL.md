# Modulo Warehouse (Magazzino, Fornitori & Ordini d'Acquisto)

Questo modulo aggiunge a Gestoray la gestione completa del magazzino multi-deposito, anagrafica fornitori, ordini di acquisto con calcolo automatico dei totali, movimentazioni di carico/scarico/trasferimento e valorizzazione CMP/FIFO.

## Requisiti
- Modulo `products` installato.

## Installazione Rapida CLI
```bash
npm run module:install -- --name warehouse
```

## Disinstallazione Rapida CLI
```bash
npm run module:uninstall -- --name warehouse
```
