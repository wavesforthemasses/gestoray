# Modulo Target & Budgeting (`targets`)

Modulo per la definizione e il monitoraggio di target prestazionali multi-periodo (settimanali, mensili, annuali) su soggetti assegnati (utenti, team, azienda) con calcolo real-time dell'avanzamento sui KPI dell'ecosistema.

## Requisiti
- Modulo `chart` installato.

## Installazione Rapida CLI
```bash
npm run module:install -- --name targets
```

## Disinstallazione Rapida CLI
```bash
npm run module:uninstall -- --name targets
```
