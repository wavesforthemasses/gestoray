# 📦 Modulo Gestione Cantieri & Commesse (`cantieri`)

Modulo puro agnostico per la gestione dei cantieri, delle commesse e dei progetti aziendali.

## Installazione Automatica
```bash
npm run module:install -- --name cantieri
```

## Disinstallazione Automatica
```bash
npm run module:uninstall -- --name cantieri
```
